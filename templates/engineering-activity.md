# Engineering Activity Authoring Template

Use this template for one factual engineering-activity entry. It is an authoring aid, not a runtime schema.

Use concise plain English and publish only claims supported by evidence.

## Date range

**Start month**

Record the factual start month at the precision supported by evidence.

**End month / current**

Record the factual end month, or state that the activity is current only when true.

## Activity kind

Choose the factual concept that best describes the period:

- `EMPLOYMENT`
- `INDEPENDENT_ENGINEERING`
- `PROFESSIONAL_DEVELOPMENT`
- `EDUCATION`
- `CAREER_BREAK`

These labels are content semantics; they do not require a runtime enum.

## Factual label

Use a short label that describes the activity without implying an employer, client, company, or commercial relationship that evidence does not support.

## Concise summary

State what was actually built, learned, maintained, researched, or owned during the period.

Avoid defensive career-gap explanation, inflated adjectives, and unsupported outcome language.

## Work / evidence links

List repositories, revisions, tasks, reviews, deployed surfaces, certificates, or other direct sources only when they substantively support the entry.

## Claim-source notes

For each material claim, note the supporting source and any limitation needed to prevent overstatement.

## Employment-truth check

Answer explicitly before publication:

**Does this wording imply employment, freelancing, client work or company experience that the evidence does not support?**

If yes, the entry is not publishable in that form. Rewrite it factually or omit it.
